# W07: immutable strategy definitions and native status

Strategy configurations are append-only SQL definition versions. The version contains an increasing ordinal and SHA-256 of canonical JSON parameters. Updating parameters publishes a new version in the same transaction as the instance CAS and operation receipt. Old intent plans retain the definition ID, version and parameters digest through an immutable composite foreign key. Preparing and beginning a risk increase reject configuration drift.

Start and stop both advance instance policy revisions. Idempotent mutation retries return the originally committed instance snapshot. Automatic closed-bar decisions include the strategy version, and execution rejects a version changed after the signal was evaluated.

`strategies.status` reads one indexed instance and returns at most 50 owned position lots, an explicit partial flag, budget/revision, exact NAV window and financial risk. It does not scan terminal order history.
